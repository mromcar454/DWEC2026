EJERCICIO 1. RECURSIVIDAD: SUMA DE DÍGITOS (2 PUNTOS)
------------------------------------------------------

Implementa una función llamada sumarDigitos(numero) que reciba un número
entero positivo y devuelva la suma de todos sus dígitos utilizando
recursividad.

No se permite convertir el número a una cadena de texto.

Ejemplos:

sumarDigitos(1234); // 10
sumarDigitos(508);  // 13
sumarDigitos(7);    // 7
sumarDigitos(1000); // 1

Requisitos:

- Debe existir un caso base.
- La función debe realizar una llamada recursiva.
- No se permite utilizar bucles.
- Se puede utilizar el operador % y Math.floor().


EJERCICIO 2. PARÁMETROS REST Y OPERADOR SPREAD (2 PUNTOS)
----------------------------------------------------------

Implementa una función llamada crearPerfil(nombre, edad, ...aficiones) que
devuelva un objeto con la siguiente estructura:

{
    nombre: "Ana",
    edad: 20,
    aficiones: ["leer", "nadar", "viajar"]
}

Después, implementa una función llamada combinarPerfiles(...perfiles) que
reciba un número variable de perfiles y devuelva un nuevo array con todos
ellos.

Para realizar la llamada de prueba se debe utilizar el operador Spread.

Ejemplo:

const aficiones = ["leer", "nadar", "viajar"];

const perfil1 = crearPerfil("Ana", 20, ...aficiones);
const perfil2 = crearPerfil("Luis", 22, "videojuegos", "cine");

const perfiles = combinarPerfiles(...[perfil1, perfil2]);

console.log(perfiles);

Resultado esperado:

[
    {
        nombre: "Ana",
        edad: 20,
        aficiones: ["leer", "nadar", "viajar"]
    },
    {
        nombre: "Luis",
        edad: 22,
        aficiones: ["videojuegos", "cine"]
    }
]

Requisitos:

- Utiliza parámetros Rest en las funciones.
- Utiliza el operador Spread en las llamadas de prueba.
- No accedas a arguments.


EJERCICIO 3. CLAUSURAS: GENERADOR DE IDENTIFICADORES (2 PUNTOS)
---------------------------------------------------------------

Implementa una función crearGenerador(prefijo) que devuelva otra función.
Cada vez que se ejecute la función devuelta debe generar un identificador
distinto, formado por el prefijo, un guion y un número consecutivo que
empiece en 1.

Ejemplo:

const generarAlumno = crearGenerador("ALU");

console.log(generarAlumno()); // "ALU-1"
console.log(generarAlumno()); // "ALU-2"
console.log(generarAlumno()); // "ALU-3"

Comprueba también que dos generadores mantienen contadores independientes:

const generarProducto = crearGenerador("PRO");

console.log(generarProducto()); // "PRO-1"
console.log(generarAlumno());   // "ALU-4"

Requisitos:

- Utiliza una clausura para guardar el contador.
- El contador no puede ser una propiedad pública ni una variable global.
- Cada llamada a crearGenerador debe crear un contador independiente.


EJERCICIO 4. CURRYING O ACARREO: CLASIFICACIÓN DE NOTAS (2 PUNTOS)
------------------------------------------------------------------

Implementa una función currificada llamada clasificarNota que reciba una nota
mínima para aprobar y después una nota. Debe devolver "Aprobado" si la nota
es mayor o igual que la mínima y "Suspenso" en caso contrario.

La función debe recibir los parámetros uno a uno:

clasificarNota(minimo)(nota)

Ejemplo:

const clasificar = clasificarNota(5);

console.log(clasificar(7)); // "Aprobado"
console.log(clasificar(4)); // "Suspenso"

La función debe poder reutilizarse con otro límite:

const clasificarConNotable = clasificarNota(7);

console.log(clasificarConNotable(8)); // "Aprobado"
console.log(clasificarConNotable(6)); // "Suspenso"

Requisitos:

- Cada función debe recibir un único parámetro.
- Debe utilizar currying o acarreo.
- Debe ser posible guardar y reutilizar una configuración parcial.
- No se permite implementar la función recibiendo los dos parámetros a la vez.


EJERCICIO 5. CALLBACKS: ANÁLISIS DE NOTAS (2 PUNTOS)
-----------------------------------------------------

Implementa una función llamada analizarNotas(notas, callback).

El parámetro notas será un array de números, por ejemplo:

const notas = [4, 7, 5, 9, 3];

La función debe recorrer el array y calcular:

1. La suma de todas las notas.
2. La cantidad de notas.
3. La cantidad de notas aprobadas, considerando aprobado a partir de 5.

Cuando termine los cálculos, debe llamar al callback y pasarle esos tres
resultados, en ese orden.

Ejemplo:

analizarNotas(notas, (suma, cantidad, aprobados) => {
    console.log(`La suma es ${suma}`);
    console.log(`Se han corregido ${cantidad} notas`);
    console.log(`Han aprobado ${aprobados} alumnos`);
});

Resultado esperado:

La suma es 28
Se han corregido 5 notas
Han aprobado 3 alumnos

Utiliza también la función con otro callback que calcule y muestre la nota
media:

analizarNotas(notas, (suma, cantidad) => {
    console.log(`La nota media es ${suma / cantidad}`);
});

Requisitos:

- analizarNotas debe recibir y utilizar un callback.
- El callback debe ejecutarse después de recorrer y calcular los datos.
- La función debe funcionar con cualquier array de notas.
- No se debe escribir ningún mensaje directamente dentro de analizarNotas.
